# Support policy

## Release support

- **v1.0.10:** current supported stable release.
- **v1.0.9:** historical validated baseline; no longer supported.
- **v1.0.0-v1.0.8:** archived, unsupported historical test builds.

Support means repository maintenance and consideration of reproducible defects;
it is not a service-level agreement and does not guarantee compatibility with
every Windows build, network, provider, payment gateway, or security product.

## Getting help

Use GitHub Issues for reproducible, non-sensitive defects and documentation
questions. Include the Tower Browser version, Windows version, exact steps,
expected and actual behavior, and sanitized logs. Remove identity addresses,
credentials, payment information, checkout URLs, tokens, and private paths.

Feature requests should describe the user problem and privacy/security impact.
For vulnerabilities, follow [SECURITY.md](SECURITY.md) and do not disclose
sensitive details publicly.

External Mysterium provider availability, identity registration, payment
processing, checkout completion, and wallet credit are outside this
repository's direct operational control.
